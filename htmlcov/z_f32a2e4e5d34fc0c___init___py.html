7#: Shared readout-panel design tokens. 

8#: 

9#: The HSI's integral readout panel (P5a) established the house look for a 

10#: value read off a moving background: a rounded container over a translucent 

11#: black fill, bordered in the foreground colour. P5c extends the same look to 

12#: the airspeed/altitude tape readout boxes, which previously used a solid 

13#: white-on-black rectangle with bracket "arms" and an opaque black triangle. 

14#: Every instrument that draws one goes through the two functions below, so the 

15#: HSI panel and the tape boxes cannot drift apart. 

16#: 

17#: The fill is deliberately translucent rather than solid: these boxes sit over 

18#: the SVS/attitude background, and a solid block reads as a hole punched in 

19#: the scene. 0.62 keeps a white value well above the WCAG 4.5:1 contrast floor 

20#: even over a fully-lit sky (see tests/instruments/test_readout_panel.py). 

21READOUT_FILL_ALPHA = 0.62 

22READOUT_BORDER_ALPHA = 0.85 

23#: Corner radius and border width, both as a fraction of the readout's font 

24#: size, so the panel scales with the instrument instead of with the screen. 

25#: This is the HSI's own token (its top_panel readout uses it directly against 

26#: `self.fontSize`) -- do not repoint the tape boxes at it, see 

27#: TAPE_READOUT_RADIUS_RATIO below. 

28READOUT_RADIUS_RATIO = 0.35 

29READOUT_PEN_RATIO = 0.06 

30#: Tape readout box (airspeed/altitude) corner radius, as a fraction of the 

31#: box's OWN base quantity: `font_height`, the fitted digit glyph height in 

32#: NumericalDisplay (panel height there is 1.20 * font_height). This is a 

33#: separate token from READOUT_RADIUS_RATIO on purpose (AER-386, Bill 

34#: 2026-08-27: "the roundedness of the airspeed and altitude boxes is too 

35#: much"): READOUT_RADIUS_RATIO is keyed to the HSI's `fontSize`, a different 

36#: base quantity, and the tape box is much shorter relative to its own font 

37#: than the HSI panel is to its own fontSize -- reusing 0.35 against 

38#: font_height ate ~29% of the tape box's height (near the geometric max 

39#: before QPainter clamps a rounded rect to a full stadium/pill -- confirmed 

40#: by rendering, see below) versus ~14.5% for the HSI's panel. 

41#: 

42#: Calibrated by rendering both at the sizes they occupy on a real PFD 

43#: (virtual_vfr.yaml's grid, at 1920x1080): the HSI top_panel panel there is 

44#: 950x950 (font_percent 0.05 -> fontSize 48 -> radius 48*0.35 = 16.8px, 

45#: 14.5% of its 115.52px panel height). Reusing that ABSOLUTE 16.8px on the 

46#: tape box (font_percent 0.25/0.24 -> font_height 22.0, panel height 

47#: 1.20*22.0 = 26.4px) exceeds half the panel height, so QPainter clamps it to 

48#: a full pill -- visually indistinguishable from the too-round original and 

49#: not a fix (rendered and compared to confirm). Matching the HSI's 

50#: *proportion* instead -- radius = 14.5% of panel height = 0.145 * 26.4 = 

51#: 3.84px -- reads as the same restrained, boxy corner as the HSI. As a 

52#: fraction of font_height that is 3.84 / 22.0 = 0.1745, rounded to 0.17 

53#: (3.74px at that font_height). 

54TAPE_READOUT_RADIUS_RATIO = 0.17

89#: Shared static-element drop-shadow tokens (AER-392 / pyEfis#142). 

90#: 

91#: A soft drop shadow under a static instrument element (the HSI rose, the 

92#: readout panel, and -- once #140 lands -- the nav-source tab) reads as a 

93#: house depth treatment, same precedent as READOUT_RADIUS_RATIO/ 

94#: TAPE_READOUT_RADIUS_RATIO above. Config-gated per widget (default OFF); 

95#: these tokens are only the shared LOOK, not the per-frame cost decision -- 

96#: see bake_blurred_silhouette() below for how it is applied without paying 

97#: per-frame blur cost. 

98#: 

99#: HARD CONSTRAINT: no per-frame gaussian blur. The HSI was ~24% of GIL time 

100#: in flight before its rose bake landed (#94); a QGraphicsEffect applied to 

101#: a live view undoes that. bake_blurred_silhouette() exists to bake the blur 

102#: exactly once, into a cached image, so a shadow costs one blit per frame 

103#: like the rose/overlay caches it sits beside. (A raw 

104#: QGraphicsDropShadowEffect on a scene item -- Option 2, AER-392 -- was 

105#: used for the HSI rose disc until AER-439: Qt's effect draws the item's 

106#: own source back on top of an UNPUNCHED blurred halo, so it tints any 

107#: translucent item with its own shadow the same way the pre-AER-415 

108#: bake_blurred_silhouette did, and exposes no punch-out knob to fix that. 

109#: bake_blurred_silhouette is the only supported mechanism now -- it already 

110#: punches its own shape back out (see AER-415 below).) 

111SHADOW_COLOR = QColor(0, 0, 0) 

112SHADOW_ALPHA = 0.6 

113#: Blur radius as a fraction of the shadowed element's own characteristic 

114#: size (the HSI passes its own fontSize, the same base unit READOUT_* 

115#: above uses) -- so the shadow scales with the instrument, not the screen. 

116SHADOW_BLUR_RATIO = 0.12 

117#: A drop shadow implies a FIXED light source. Content that gets baked once 

118#: and then rotated per-frame (the HSI rose card turns with heading) must 

119#: not carry a directional offset, or the implied light appears to swing 

120#: with heading (AER-392 gotcha #1) -- a symmetric, zero-offset blur halo is 

121#: the only offset that is rotation-safe. bake_blurred_silhouette() has no 

122#: offset parameter for this reason: every current consumer (the rose, the 

123#: readout panel, the tape boxes) wants the same centred halo. 

124#: A Gaussian blur needs room past the shadowed shape's own edge to fully 

125#: resolve. Baking directly into a canvas sized to just the shape (or to the 

126#: shape's on-screen position with no margin) clips the falloff into a hard, 

127#: rectangular edge partway through the halo -- it reads as a rendering bug, 

128#: not a soft shadow (AER-392 gotcha #2). This is the margin, as a multiple 

129#: of the blur radius, reserved on every side: both for the bake canvas 

130#: itself (see bake_blurred_silhouette) and for callers deciding how much 

131#: on-screen clearance a shadow needs before it is safe to draw at all 

132#: (see the HSI's rose-radius reservation and its readout-panel margin cap). 

133SHADOW_CANVAS_PAD_RATIO = 3.0

136def bake_blurred_silhouette(width, height, paint_shape, blur_radius, 

137 color=SHADOW_COLOR, alpha=SHADOW_ALPHA): 

138 """Bake a blurred, flat-colour silhouette of a shape into a QImage ONCE 

139 (Option 4, AER-392): for static screen-fixed geometry that is painted 

140 fresh every frame with a QPainter (the HSI's readout-panel/box shells, 

141 and -- once #140 lands -- the nav-source tab), so a soft shadow still 

142 costs zero per-frame blur work. The silhouette is colour- and 

143 content-independent, so one bake serves every value/state the shape's 

144 live content can take (AER-392 gotcha #3). 

145 

146 `paint_shape(painter)` draws the OPAQUE shape at its normal (widget) 

147 position/size -- e.g. `painter.drawRoundedRect(rect, radius, radius)`. 

148 Only the painted coverage matters; this function flattens it to 

149 `color`/`alpha`, blurs it, then punches `paint_shape`'s own coverage 

150 back OUT of the blurred result (AER-415) -- the interior is zero, and 

151 only the falloff that extends past the shape's edge survives. Without 

152 this, the halo is a solid filled silhouette under the shape's own 

153 footprint, and a caller that blits it under a translucent fill (e.g. 

154 the readout panel's `READOUT_FILL_ALPHA`) gets that solid fill reading 

155 straight through, tinting the whole interior instead of just its edge. 

156 

157 Returns `(image, pad)`. `image` is sized `(width + 2*pad, height + 

158 2*pad)` -- the pad reserves room for the Gaussian to fully resolve 

159 before the canvas edge (SHADOW_CANVAS_PAD_RATIO; omitting it clips the 

160 falloff into a hard square edge, gotcha #2). Blit the result at 

161 `(-pad, -pad)` in the caller's own widget-sized target so the 

162 silhouette lines up with the shape as `paint_shape` drew it. 

163 """ 

164 pad = int(math.ceil(max(0.0, float(blur_radius)) * SHADOW_CANVAS_PAD_RATIO)) 

165 w, h = int(width) + 2 * pad, int(height) + 2 * pad 

166 

167 shape = QImage(w, h, QImage.Format.Format_ARGB32_Premultiplied) 

168 shape.fill(0) 

169 sp = QPainter(shape) 

170 sp.setRenderHint(QPainter.RenderHint.Antialiasing) 

171 sp.translate(pad, pad) 

172 paint_shape(sp) 

173 sp.end() 

174 

175 # Flatten the shape's coverage (its alpha channel) to one flat shadow 

176 # colour -- SourceIn keeps only the destination fill where the source 

177 # (the shape we just painted) was opaque. 

178 silhouette = QImage(w, h, QImage.Format.Format_ARGB32_Premultiplied) 

179 silhouette.fill(0) 

180 tp = QPainter(silhouette) 

181 tp.setCompositionMode(QPainter.CompositionMode.CompositionMode_Source) 

182 tp.drawImage(0, 0, shape) 

183 tp.setCompositionMode(QPainter.CompositionMode.CompositionMode_SourceIn) 

184 fill = QColor(color) 

185 fill.setAlphaF(max(0.0, min(1.0, float(alpha)))) 

186 tp.fillRect(0, 0, w, h, fill) 

187 tp.end() 

188 

189 scene = QGraphicsScene(0, 0, w, h) 

190 item = scene.addPixmap(QPixmap.fromImage(silhouette)) 

191 blur = QGraphicsBlurEffect() 

192 blur.setBlurRadius(blur_radius) 

193 blur.setBlurHints(QGraphicsBlurEffect.BlurHint.QualityHint) 

194 item.setGraphicsEffect(blur) 

195 

196 out = QImage(w, h, QImage.Format.Format_ARGB32_Premultiplied) 

197 out.fill(0) 

198 op = QPainter(out) 

199 op.setRenderHint(QPainter.RenderHint.Antialiasing) 

200 scene.render(op, QRectF(0, 0, w, h), QRectF(0, 0, w, h)) 

201 op.end() 

202 

203 # Punch the original opaque shape back out of its own blurred halo 

204 # (AER-415): the blur above smears the FULL filled silhouette outward, 

205 # so without this the baked image still carries a solid, flat-colour 

206 # fill everywhere the shape itself covers. Blitted under a panel whose 

207 # own fill is translucent by design (READOUT_FILL_ALPHA), that filled 

208 # interior reads straight through and tints the whole panel body, not 

209 # just the edge falloff. DestinationOut with the SAME path at the SAME 

210 # position removes exactly the shape's own coverage, leaving only the 

211 # soft falloff that extends past its edge. 

212 punch = QPainter(out) 

213 punch.setRenderHint(QPainter.RenderHint.Antialiasing) 

214 punch.setCompositionMode(QPainter.CompositionMode.CompositionMode_DestinationOut) 

215 punch.translate(pad, pad) 

216 paint_shape(punch) 

217 punch.end() 

218 

219 return out, pad
