26#: Shared readout-panel design tokens. 

27#: 

28#: The HSI's integral readout panel (P5a) established the house look for a 

29#: value read off a moving background: a rounded container over a translucent 

30#: black fill, bordered in the foreground colour. P5c extends the same look to 

31#: the airspeed/altitude tape readout boxes, which previously used a solid 

32#: white-on-black rectangle with bracket "arms" and an opaque black triangle. 

33#: Every instrument that draws one goes through the two functions below, so the 

34#: HSI panel and the tape boxes cannot drift apart. 

35#: 

36#: The fill is deliberately translucent rather than solid: these boxes sit over 

37#: the SVS/attitude background, and a solid block reads as a hole punched in 

38#: the scene. 0.62 keeps a white value well above the WCAG 4.5:1 contrast floor 

39#: even over a fully-lit sky (see tests/instruments/test_readout_panel.py). 

40READOUT_FILL_ALPHA = 0.62 

41READOUT_BORDER_ALPHA = 0.85 

42#: Corner radius of a rounded readout container, as a fraction of the 

43#: container's OWN panel height -- so every readout box in the house style gets 

44#: the same corner from ONE number, with no per-widget arithmetic: the HSI's 

45#: HDG|MAG|CRS panel, the airspeed/altitude tape boxes, the airspeed TAS box, 

46#: and any future rounded container (the nav-source tab, #143). Keyed to panel 

47#: HEIGHT -- not to a font size, and not to a panel-height multiplier -- on 

48#: purpose (AER-386/AER-413; Bill 2026-08-27: "we will likely be using it some 

49#: more"). 

50#: 

51#: Why height, and why 0.145 -- the derivation is kept because it is the reason 

52#: absolute-pixel matching fails. Calibrated by rendering both containers at 

53#: the sizes they occupy on a real PFD (virtual_vfr.yaml's grid, at 1920x1080): 

54#: the HSI top_panel panel there is 950x950 (font_percent 0.05 -> fontSize 48), 

55#: and its sectioned readout panel is 115.52px tall with a 16.8px corner -- 

56#: 16.8 / 115.52 = 0.145 of its own height. Reusing that ABSOLUTE 16.8px on the 

57#: much shorter tape box (font_percent 0.25/0.24 -> font_height 22.0, panel 

58#: height 1.20 * 22.0 = 26.4px) exceeds half the panel height, so QPainter 

59#: clamps it to a full pill -- visually indistinguishable from the too-round 

60#: original and not a fix (rendered and compared to confirm). Matching the 

61#: HSI's *proportion* instead -- 0.145 * 26.4 = 3.84px -- reads as the same 

62#: restrained, boxy corner as the HSI. 

63#: 

64#: The earlier TAPE_READOUT_RADIUS_RATIO folded the 1.20 panel-height 

65#: multiplier (_READOUT_PANEL_H in NumericalDisplay) into the token: 0.145 * 

66#: 1.20 = 0.174 against font_height. Keying to panel height directly means a 

67#: change to that multiplier moves the panel and its corner together instead of 

68#: silently breaking the HSI match -- pinned by test_readout_panel.py (AER-413). 

69READOUT_RADIUS_RATIO = 0.145 

70#: Border width as a fraction of the readout's font size. 

71READOUT_PEN_RATIO = 0.06

181def _srgb_to_linear(channel): 

182 c = channel / 255.0 

183 return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4

186def _relative_luminance(rgb): 

187 r, g, b = (_srgb_to_linear(c) for c in rgb) 

188 return 0.2126 * r + 0.7152 * g + 0.0722 * b

191def contrast_ratio(fg_color, bg_color): 

192 """WCAG 2.x contrast ratio between two QColor-able values.""" 

193 fg, bg = QColor(fg_color), QColor(bg_color) 

194 l1 = _relative_luminance((fg.red(), fg.green(), fg.blue())) 

195 l2 = _relative_luminance((bg.red(), bg.green(), bg.blue())) 

196 if l1 < l2: 

197 l1, l2 = l2, l1 

198 return (l1 + 0.05) / (l2 + 0.05)

223#: Shared static-element drop-shadow tokens (AER-392 / pyEfis#142). 

224#: 

225#: A soft drop shadow under a static instrument element (the HSI rose, the 

226#: readout panel, and -- once #140 lands -- the nav-source tab) reads as a 

227#: house depth treatment, same precedent as READOUT_RADIUS_RATIO above. 

228#: Config-gated per widget (default OFF); 

229#: these tokens are only the shared LOOK, not the per-frame cost decision -- 

230#: see bake_blurred_silhouette() below for how it is applied without paying 

231#: per-frame blur cost. 

232#: 

233#: HARD CONSTRAINT: no per-frame gaussian blur. The HSI was ~24% of GIL time 

234#: in flight before its rose bake landed (#94); a QGraphicsEffect applied to 

235#: a live view undoes that. bake_blurred_silhouette() exists to bake the blur 

236#: exactly once, into a cached image, so a shadow costs one blit per frame 

237#: like the rose/overlay caches it sits beside. (A raw 

238#: QGraphicsDropShadowEffect on a scene item -- Option 2, AER-392 -- was 

239#: used for the HSI rose disc until AER-439: Qt's effect draws the item's 

240#: own source back on top of an UNPUNCHED blurred halo, so it tints any 

241#: translucent item with its own shadow the same way the pre-AER-415 

242#: bake_blurred_silhouette did, and exposes no punch-out knob to fix that. 

243#: bake_blurred_silhouette is the only supported mechanism now -- it already 

244#: punches its own shape back out (see AER-415 below).) 

245SHADOW_COLOR = QColor(0, 0, 0) 

246SHADOW_ALPHA = 0.6 

247#: Blur radius as a fraction of the shadowed element's own characteristic 

248#: size (the HSI passes its own fontSize, the same base unit READOUT_* 

249#: above uses) -- so the shadow scales with the instrument, not the screen. 

250SHADOW_BLUR_RATIO = 0.12 

251#: A drop shadow implies a FIXED light source. Content that gets baked once 

252#: and then rotated per-frame (the HSI rose card turns with heading) must 

253#: not carry a directional offset, or the implied light appears to swing 

254#: with heading (AER-392 gotcha #1) -- a symmetric, zero-offset blur halo is 

255#: the only offset that is rotation-safe. bake_blurred_silhouette() has no 

256#: offset parameter for this reason: every current consumer (the rose, the 

257#: readout panel, the tape boxes) wants the same centred halo. 

258#: A Gaussian blur needs room past the shadowed shape's own edge to fully 

259#: resolve. Baking directly into a canvas sized to just the shape (or to the 

260#: shape's on-screen position with no margin) clips the falloff into a hard, 

261#: rectangular edge partway through the halo -- it reads as a rendering bug, 

262#: not a soft shadow (AER-392 gotcha #2). This is the margin, as a multiple 

263#: of the blur radius, reserved on every side: both for the bake canvas 

264#: itself (see bake_blurred_silhouette) and for callers deciding how much 

265#: on-screen clearance a shadow needs before it is safe to draw at all 

266#: (see the HSI's readout-panel margin cap). 

267SHADOW_CANVAS_PAD_RATIO = 3.0 

268#: Alpha profile of a rim glow, as (distance across the glow band, fraction of 

269#: peak alpha). Distance 0.0 is the shape's own edge, 1.0 is the outer limit of 

270#: the glow. A rim glow is a symmetric, zero-offset halo -- it reads as a drop 

271#: shadow cast by a light source at infinite distance, which is the intended 

272#: look for the HSI rose (an offset shadow could not be, since the rose bake 

273#: is rotated per heading; AER-392 gotcha #1). 

274#: 

275#: Why a gradient and not a blur (pyEfis#158 follow-up): blurring a filled 

276#: silhouette and punching the shape back out gives no direct control over 

277#: either the glow's width or its peak opacity. A Gaussian step edge lands at 

278#: only ~50% of the fill alpha right at the shape's edge, and its tail runs far 

279#: wider than the nominal blur radius -- so the rose's halo came out both too 

280#: faint and too diffuse to read as a shadow. Stating the profile outright 

281#: makes both properties exact and costs no blur pass. 

282#: 

283#: Eased rather than linear so the outer limit fades out instead of ending on 

284#: a visible edge. 

285RIM_GLOW_FALLOFF = ((0.0, 1.0), (0.35, 0.55), (0.65, 0.25), (1.0, 0.0))

288def bake_blurred_silhouette(width, height, paint_shape, blur_radius, 

289 color=SHADOW_COLOR, alpha=SHADOW_ALPHA): 

290 """Bake a blurred, flat-colour silhouette of a shape into a QImage ONCE 

291 (Option 4, AER-392): for static screen-fixed geometry that is painted 

292 fresh every frame with a QPainter (the HSI's readout-panel/box shells, 

293 and -- once #140 lands -- the nav-source tab), so a soft shadow still 

294 costs zero per-frame blur work. The silhouette is colour- and 

295 content-independent, so one bake serves every value/state the shape's 

296 live content can take (AER-392 gotcha #3). 

297 

298 `paint_shape(painter)` draws the OPAQUE shape at its normal (widget) 

299 position/size -- e.g. `painter.drawRoundedRect(rect, radius, radius)`. 

300 Only the painted coverage matters; this function flattens it to 

301 `color`/`alpha`, blurs it, then punches `paint_shape`'s own coverage 

302 back OUT of the blurred result (AER-415) -- the interior is zero, and 

303 only the falloff that extends past the shape's edge survives. Without 

304 this, the halo is a solid filled silhouette under the shape's own 

305 footprint, and a caller that blits it under a translucent fill (e.g. 

306 the readout panel's `READOUT_FILL_ALPHA`) gets that solid fill reading 

307 straight through, tinting the whole interior instead of just its edge. 

308 

309 Returns `(image, pad)`. `image` is sized `(width + 2*pad, height + 

310 2*pad)` -- the pad reserves room for the Gaussian to fully resolve 

311 before the canvas edge (SHADOW_CANVAS_PAD_RATIO; omitting it clips the 

312 falloff into a hard square edge, gotcha #2). Blit the result at 

313 `(-pad, -pad)` in the caller's own widget-sized target so the 

314 silhouette lines up with the shape as `paint_shape` drew it. 

315 """ 

316 pad = int(math.ceil(max(0.0, float(blur_radius)) * SHADOW_CANVAS_PAD_RATIO)) 

317 w, h = int(width) + 2 * pad, int(height) + 2 * pad 

318 

319 shape = QImage(w, h, QImage.Format.Format_ARGB32_Premultiplied) 

320 shape.fill(0) 

321 sp = QPainter(shape) 

322 sp.setRenderHint(QPainter.RenderHint.Antialiasing) 

323 sp.translate(pad, pad) 

324 paint_shape(sp) 

325 sp.end() 

326 

327 # Flatten the shape's coverage (its alpha channel) to one flat shadow 

328 # colour -- SourceIn keeps only the destination fill where the source 

329 # (the shape we just painted) was opaque. 

330 silhouette = QImage(w, h, QImage.Format.Format_ARGB32_Premultiplied) 

331 silhouette.fill(0) 

332 tp = QPainter(silhouette) 

333 tp.setCompositionMode(QPainter.CompositionMode.CompositionMode_Source) 

334 tp.drawImage(0, 0, shape) 

335 tp.setCompositionMode(QPainter.CompositionMode.CompositionMode_SourceIn) 

336 fill = QColor(color) 

337 fill.setAlphaF(max(0.0, min(1.0, float(alpha)))) 

338 tp.fillRect(0, 0, w, h, fill) 

339 tp.end() 

340 

341 scene = QGraphicsScene(0, 0, w, h) 

342 item = scene.addPixmap(QPixmap.fromImage(silhouette)) 

343 blur = QGraphicsBlurEffect() 

344 blur.setBlurRadius(blur_radius) 

345 blur.setBlurHints(QGraphicsBlurEffect.BlurHint.QualityHint) 

346 item.setGraphicsEffect(blur) 

347 

348 out = QImage(w, h, QImage.Format.Format_ARGB32_Premultiplied) 

349 out.fill(0) 

350 op = QPainter(out) 

351 op.setRenderHint(QPainter.RenderHint.Antialiasing) 

352 scene.render(op, QRectF(0, 0, w, h), QRectF(0, 0, w, h)) 

353 op.end() 

354 

355 # Punch the original opaque shape back out of its own blurred halo 

356 # (AER-415): the blur above smears the FULL filled silhouette outward, 

357 # so without this the baked image still carries a solid, flat-colour 

358 # fill everywhere the shape itself covers. Blitted under a panel whose 

359 # own fill is translucent by design (READOUT_FILL_ALPHA), that filled 

360 # interior reads straight through and tints the whole panel body, not 

361 # just the edge falloff. DestinationOut with the SAME path at the SAME 

362 # position removes exactly the shape's own coverage, leaving only the 

363 # soft falloff that extends past its edge. 

364 punch = QPainter(out) 

365 punch.setRenderHint(QPainter.RenderHint.Antialiasing) 

366 punch.setCompositionMode(QPainter.CompositionMode.CompositionMode_DestinationOut) 

367 punch.translate(pad, pad) 

368 paint_shape(punch) 

369 punch.end() 

370 

371 return out, pad
